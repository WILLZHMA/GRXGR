# 原始碼與建置（選用）

六份獨立版是由這裡的共用原始碼建置出來的。**平常不需要碰這個資料夾**；六個資料夾本身就是成品，可以直接修改、直接上架。

## 什麼時候用
想「一次改六份」時（例如全部換配色、全部加一個欄位），改 `src/` 裡的檔案，然後在這個資料夾執行：

    python build.py 輸出資料夾

會把六個資料夾、`入口.html`、`說明.md` 重新產生到你指定的位置（需要 Python 3，不用安裝其他套件；不給輸出資料夾就會放在這裡的 `dist/`）。

## 單獨上架：關掉「切換版本」
每一份右上角的「切換版本」只是連到上一層的 `入口.html` 與其他版本資料夾，方便你在本機來回看。**單獨上架時不需要它**：

    python build.py 輸出資料夾 --no-hub

會產生沒有切換連結、也沒有 `入口.html` 的六份。只想關掉某一份，把那份 `app.js` 最前面的 `"hub": {…}` 改成 `"hub": null` 即可。

## src 裡面有什麼
| 檔案 | 內容 | 哪幾份會用到 |
|---|---|---|
| `data.js` | 模擬資料（價格、交易量、面積、氣象、預警、新聞；含一個可開關的虛構事件 `EVT`，預設開，設定裡的「模擬突發事件」可關） | 全部 |
| `icons.js`、`art.js` | 圖示與作物插圖 | 全部 |
| `calc_common.js` | 共用計算（價格走勢、漲跌、日期格式） | 全部 |
| `core.js` | 狀態、設定記憶、備份代碼、圖表 | 全部 |
| `shell.js` | 版面外框、導覽、設定面板 | 全部 |
| `pages.js` | 價格行情、面積與產量、氣象、知識與新聞 | 全部 |
| `home_farmer.js` | 農友／消費者首頁 | 農友、消費者 |
| `calc_policy.js`、`calc_event.js`、`home_policy.js` | 政策者的指數與訊號、事件偵測與答詢重點（門檻為示意值）、決策總覽首頁 | 政策者（手機、電腦） |
| `calc_research.js`、`home_researcher.js`、`notes.js` | 研究者的相關分析、首頁、研究筆記 | 研究者（手機、電腦） |
| `main.js` | 啟動、事件處理、救援畫面 | 全部 |
| `launcher.html` | 入口頁（標題區、新聞／上中下價／整體統計三個分頁、六個版本選單） | 只有入口頁（會把 `data.js`、`calc_common.js`、`calc_policy.js` 直接放進頁面，所以數字與六個版本一致） |
| `styles.css` | 樣式 | 全部 |

## 要新增一份（例如電腦版農友）
在 `build.py` 的 `APPS` 加一行：資料夾名、身分（farmer／buyer／policy／researcher）、版面（phone／desk）、標題、說明；再執行 build。

## 示範用的虛構事件（EVT）
`src/data.js` 的 `EVT` 控制：事件作物（`crop`）、市場（`market`）、跌幅（`drop`）、交易量增幅（`volUp`）、前幾天開始（`ramp`）。要換成別的事件改這幾個值；`on:false` 就沒有事件。接上真實資料後整段 `EVT` 與設定裡的開關都應移除。
